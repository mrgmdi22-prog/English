## Structure
- `index.html` home (order): hero (title + my stars/points) → continue card → honor board → «ابدأ من هنا» (1 دليل المتعلم, 2 قياس المستوى) → install card → «اختر القسم» picker (6 tiles) → shelves: Foundations #f1, Vocabulary #f2, Grammar #f3, Capsules #f5 (10 chips), Reading & Speaking #f4, «مواقع إضافية» (enrichment links + Arabic Harbours) → Kids Club #kids last.
- `assets/gate.js?v=9` registration gate (loads `sfx.js?v=9`); `assets/club.js?v=12` remembers last page + syncs points + Surprise Me floating 🎁 button/nudge; `assets/sfx.js` site sounds (kalimba right, low "uh-oh" wrong) + 🔊 switch + service worker registration + Android "open in Chrome".
- `assets/honor.js?v=20261101g` Firebase (project `english-club-score`): students start anonymous, then their account is linked (same uid) to a recovery code `ABCD-2345` (Email/Password provider, fake email `<code>@students.english-club-score.firebaseapp.com`); teacher Google (mr.gmdi22@gmail.com). Collections: players (nick, score, parts incl. `parts.wqx`, `base` = points the teacher merged in from a lost old account), private (real name/grade/section), progress (`d` = JSON backup of the student's localStorage, merged max-wise on every device), recovery (code copy for the teacher), levels (pre/post test), config (nicks list, levels.postOpen). New device: honor.html «لدي رمز حساب» → restore(code). Code shown once on any page (showCodeOnce) and always on honor.html; teacher.html shows codes + «ضمّ حساب قديم». Rules in `firestore.rules` (Ahmed pastes them in Firebase console → Firestore → Rules → Publish).
- `surprise/` Surprise Me 🎁 صندوق المفاجآت (old `mystery/` redirects here): one box a day (same for everyone; the box's day starts at 6 am Saudi time (`today()` shifted −6 h), open 6 am–10 pm, closed 10 pm–6 am: `vClosed` view, home card + floating button hidden too), 15 MCQs (100 marks per box, 100/15 each, rounded), one per SLOT: general word (ng), academic word (aw), grammar ×2 (gr hand-written / tn / pv), sentence structure (sx, word order from capsule sentences), reading (rd, short text + question), conversation (ev), capsules — every question answerable from the screen; hand-written reading/grammar in `surprise/content.mjs`; each tagged with its section and linked back on the result screen. First box of the day saves `mb-days` {day: right} and `mb-pts` {day: marks/100} → honor rule `mb` (1 pt per mark, max 8000; old days without mb-pts count 5 per right answer); fireworks canvas on open/right answers/result; weekly titles 3/5/7 boxes: مستكشف المفاجآت 🧭 / صيّاد الكنوز 💎 / أسطورة المفاجآت 👑; replays are practice. Bank `surprise/bank.js` is GENERATED from the sections' data: rerun `node surprise/build-bank.mjs` after changing content. Home card after the honor board; floating button + one-time "you earned points, open the box" note on other pages (club.js).
- `guide.html` دليل المتعلم (Learner's guide, no gate): 4 start steps, level-based path picker (`guide-path`), 20-min daily plan, open/close card per section, points, golden rules. Home shows it as step 1 of «ابدأ من هنا», before the level check.
- `teacher.html` pending names, newest registrations, level-check results (+ open post test, CSV), Word Quest follow-up, honor list CSV.
- `level/` before/after placement test, version 2 (harder, since 1 Nov 2026): 32 Q (vocab 10, grammar 10, reading 6, listening 6), bands A1×2/A2×10/B1×10/B2×10, each pre item has a same-level twin in the post form; levels Pre-A1…B2. Results with `at` < `NEW_AT` are the old easy version: the student is asked to retake the pre test (rules allow replacing an old pre once; teacher.html marks «نسخة قديمة»). Drafts use `lv2-draft-`.
- `journey/word-quest.html` 50 units (4000 Essential English Words 1 lists + theme units): hero dashboard, journey map, daily spaced review (`wq-srs`), daily goal/streak, record-and-compare pronunciation (no automatic speech scoring — removed as unreliable).
- `kids/` home = «مسيرة البطل» journey map (`LANDS`/`ST` in kids/index.html): 27 stations in 6 lands (بستان الحروف → قمة الأبطال), each station offers 3 missions (learn / listen / read / story / write / spell / games); one finished mission opens the next station, 3 = ⭐⭐⭐; «🚀 أنا بطل متقدم» picks a land to start from (`JR.j`: first station of every land up to it opens); a chest (+5 stars) ends each land. Progress `kd-jr` {d:{'station.door':1},c:{land:1}}. Mission done = endScreen reached, 6 learn cards tapped, or 3 letters written; bottom bar `#jbar` + «ارجع إلى المحطة». The old sectioned home is now «كل الأقسام» (`allSections`, #all).
- `kids/` Kids Club (primary school): letters/numbers/colours/shapes, letter writing (tracing), 16 picture topics, phrases, classroom phrases, page-turning storybook (20 stories in 4 levels; L2–L4 have a "New Words" page; L4 = advanced, true/false questions). Home order: review box → story corner (story of the day + covers) → basics → picture words → phrases → games → advanced corner (Hero Stories, Build it! word order, Grammar, Opposites, Super Spell). Back button: every screen is a history entry (#sec / #story-n), so phone back stays inside Kids Club, read/spell/memory games, stickers; own manifest + lion-cub icon. Mistakes: wrong answer → try again (right answer glows after 2 tries), question re-asked 2 rounds later, and stored in `kd-fix` (Leitner: 10 min, 1 day, 3 days) → home "🔁 حان وقت المراجعة" box and due items mixed into the next game.
- `words/ngsl.html` (General, 50 units/1000 words, prefix `ng-`) and `words/awl.html` (Academic, 29 units/569 words in 10 sublists via `u.g`, prefix `aw-`) are built from the Word Quest design (hero dashboard, journey map, daily review, streak, record-and-compare, Cambridge + Collins) plus their own card-by-card deck view in Learn.
- `letters/`, `words/` (NGSL/AWL decks), `vocab/` (Mega Goal 1.1–3.1), `capsules/` (10 sentence capsules), `grammar/` (tenses map with A4 print sheet, passive voice `passive.html` — learn/converter/builder/quiz, quiz best → `pv-best` on the honor board — syntax tree), `idioms/`, `stories/`, `everyday/`.
- PWA: `manifest.webmanifest`, `sw.js` (club-v3: pages network-first with 3.5 s fallback to cache), `install.html`, `offline.html`.
- `sounds.html` sound preview page.
