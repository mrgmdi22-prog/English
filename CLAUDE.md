## Structure
- `index.html` home (order): hero (title + my stars/points) → continue card → honor board → «ابدأ من هنا» (1 دليل المتعلم, 2 قياس المستوى) → install card → «اختر القسم» picker (6 tiles) → shelves: Foundations #f1, Vocabulary #f2, Grammar #f3, Capsules #f5 (10 chips), Reading & Speaking #f4, «مواقع إضافية» (enrichment links + Arabic Harbours) → Kids Club #kids last.
- `assets/gate.js?v=9` registration gate (loads `sfx.js?v=9`); `assets/club.js?v=18` remembers last page + syncs points + Surprise Me floating 🎁 button/nudge; `assets/sfx.js` site sounds (kalimba right, low "uh-oh" wrong) + 🔊 switch + service worker registration + Android "open in Chrome".
- `assets/honor.js?v=20261104d` Firebase (project `english-club-score`): students start anonymous, then their account is linked (same uid) to a recovery code `ABCD-2345` (Email/Password provider, fake email `<code>@students.english-club-score.firebaseapp.com`); teacher Google (mr.gmdi22@gmail.com). Collections: players (nick, score, parts incl. `parts.wqx`, `base` = points the teacher merged in from a lost old account), private (real name/grade/section), progress (`d` = JSON backup of the student's localStorage, merged max-wise on every device), recovery (code copy for the teacher), levels (pre/post test), config (nicks list, levels.postOpen). New device: honor.html «لدي رمز حساب» → restore(code). Code shown once on any page (showCodeOnce) and always on honor.html; teacher.html shows codes + «ضمّ حساب قديم». Weekly seasons: a season starts every Tuesday 6 am Saudi (`weekNo()`, day 5 mod 7); computeScore() returns score = this season (total − `pts-day`.w0), total = all-time; players doc: score (week), week, total (+base), wk {week: pts, ≤60}; the board shows rows with week == this week; `stars(rows)` = top `STARS_N` (10) of each finished week from `FIRST_WEEK` = `FOUND_WEEK` (2964 = the founding season: all points before Tue 3 Nov 2026; old docs without `week` belong to it; in it score = all-time total incl. base); honor.html shows last week's stars + archive + most-starred; teacher.html «سجل نجوم الأسابيع», honour CSV ordered by star count then total. Writes fall back to the old fields if the published rules refuse the new ones. Surprise Me: 3 counted boxes a day (box 1 → mb-days/mb-pts, boxes 2–3 → `mb-x` {'<day>-2': pts}; seeds makeBox(day, 0..2), later boxes are practice), all outside the daily cap. Daily cap: practice points count at most `DAILY_CAP` = 900, elite 1200 (750/1000 until 4 Nov 2026, 500 until 3 Nov) a points day that starts at 6 am Saudi time (ledger `pts-day` {d, seen, got, t}; points over the cap are lost, not carried over; existing points were kept on first run); Surprise Me (mb), level gains (lv, lvs) and retention (rt) are outside the cap; honor.html shows today's progress. Rules in `firestore.rules` (Ahmed pastes them in Firebase console → Firestore → Rules → Publish).
- **Points rates & streak multiplier (since 4 Nov 2026, `RATES_V` = 2 in honor.js):** one right answer is worth the same in every section of the same level — 5 (wq, ng, mg, tb, bf, capsules, Core Quest = 50 a set), 7 (aw, st, lab, tn, pv, im, STEP `sp`), 10 (elite ek/ed). Capsule stage = ⭐ 15 / ⭐⭐ 25 / ⭐⭐⭐ 35 (7 questions). tn/pv/im count each question once via `tn-known`/`pv-known`/`im-known` (max 42/60/52; the old best still counts if larger). STEP: `step.ok` {qkey:1}, each question once, for everyone. `assets/combo.js?v=1` = مضاعف التسلسل 🔥: right answers in a row are ×1 (1st–2nd), ×1.5 (3rd–4th), ×2 (5th on); bonus kept in `xb` {sec:{unit: half-answers}}: unit mode = best attempt per unit (max 14 = a perfect ten), item mode ('*') = only for questions new to the student; honor rule `xb` (inside the daily cap; ek/ed bonus only for elite). API: start(sec, unit, {quiet}), hit(ok, fresh), run(sec, unit, bools) for tests graded at the end, line() for result screens, learn(key, id, max). Every quiz page loads it after gate.js. When the rates change, bump `RATES_V`: the ledger then re-baselines (`pts-day`.seen = raw) so past work is not re-rated. Bumping honor.js also needs club.js?v= bumped on every page (sw.js serves assets cache-first by exact URL).
- `surprise/` Surprise Me 🎁 صندوق المفاجآت (old `mystery/` redirects here): one box a day (same for everyone; the box's day starts at 6 am Saudi time (`today()` shifted −6 h), open 6 am–10 pm, closed 10 pm–6 am: `vClosed` view, home card + floating button hidden too), 15 MCQs, reward levels by right answers (`TIERS`): 7–10 → 70, 11–12 → 100, 13–15 → 150, under 7 → 0 (changed 1 Nov 2026 from 8 per answer + 30 bonus); a 🔓 pop + fireworks when a level unlocks, one per SLOT: general word (ng), academic word (aw), grammar ×2 (gr hand-written / tn / pv), sentence structure (sx, word order from capsule sentences), reading (rd, short text + question), conversation (ev), capsules — every question answerable from the screen; hand-written reading/grammar in `surprise/content.mjs`; each tagged with its section and linked back on the result screen. First box of the day saves `mb-days` {day: right} and `mb-pts` {day: points incl. bonus} → honor rule `mb` (1 pt per point, max 8000; old days without mb-pts count 5 per right answer); fireworks canvas on open/right answers/result; weekly titles 3/5/7 boxes: مستكشف المفاجآت 🧭 / صيّاد الكنوز 💎 / أسطورة المفاجآت 👑; replays are practice. Bank `surprise/bank.js` is GENERATED from the sections' data: rerun `node surprise/build-bank.mjs` after changing content. Home card after the honor board; floating button + one-time "you earned points, open the box" note on other pages (club.js).
- Learning-over-time points (honor.js): `lv` = 500 per CEFR level gained from the pre test to the BEST post, `lvs` = 10 per extra right answer (best post score − pre score), never decreasing (v2 test only); `rt` = 3 per word at SRS box ≥3 in wq/ng/aw-srs. In those pages `mark()` promotes a word only when its review is due (replays the same day don't raise the box).
- `guide.html` دليل المتعلم (Learner's guide, no gate): 4 start steps, level-based path picker (`guide-path`), 20-min daily plan, open/close card per section, points, golden rules. Home shows it as step 1 of «ابدأ من هنا», before the level check.
- `elite/index.html` مسار النخبة 💎, a game (B1+ only: a current-version level test at B1 or above unlocks it locally; the lock is a motivation gate, not security). Hero: rank title by total stars (`TITLES`: 0 مرشّح 🌱 / 5 فارس 🛡️ / 12 ماسة 💎 / 20 نجم 🌟 / 28 أسطورة 👑) + stats + progress to next title. Journey map in 2 realms (`REALMS`: قمة B1 units 1–5, قمة B2 units 6–10); stars per unit 5/8/10 right = ⭐/⭐⭐/⭐⭐⭐; a unit opens with one star in the previous one (B2-level students: all open; a unit already tried stays open). 10 units × 10 questions in `UNITS` (vocab, grammar, sentences, dialogues, reading; a[0] = right answer, shuffled on screen). Quiz: combo 🔥 with toasts at 3/5/7/10, +10 pop, site sounds (`window.clubSfx`), stars pop + fireworks on ≥8, new-record chip, title/badge/unlock toasts, mistakes review. Daily challenge ⚡ (`el-daily` {day: right}): 5 same-for-everyone questions a day (seeded by the 6 am day; no passages or «Same dialogue» items), first try counts. Badges (`BADGES`, computed): 🔥 combo ≥5 (`el-combo`), 🎯 10/10, 🏔️ all B1 ≥5, 🏰 all B2 ≥5, 🌟 20 stars, ⚡ 3 daily days. Board: podium + list via `eliteBoard()`. Points (honor.js, elite students only): `ek` = 10 per right answer of each unit's best (`el-best-<n>`), `ed` = 10 per right answer of the daily first try; both inside the elite daily cap DAILY_CAP_EL = 1200 (others 900); `parts.el` = 1 for elite. No firestore rule change: all of it lives inside the existing `parts` map.
- `elite/step/` مِران ستيب (STEP practice bank), linked from a card in elite/index.html under the daily challenge: 1399 grammar + written-analysis MCQs (24 added from the model-44 edition, checked) (answer keys reviewed by hand 4 Nov 2026; source keys had errors) in 19 skill sections (rule card per section, time-word hints for tenses) and 363 reading passages / 1105 questions (64 passages added from the newer reading-recall edition, rebuilt and checked), «مفردات القراءة المتكررة» word drill (225 curated word→meaning pairs in `window.STEP_WORDS`, appended to data.js; source list had many wrong pairs, these were checked; MCQs built on the fly with 3 random distractor meanings) (Arabic translation of each question), «الأكثر تكراراً» (seen in ≥3 model papers), mistakes review, mock test (40 reading + 26 grammar + 14 analysis, timer, per-skill result). Data `elite/step/data.js` is GENERATED from STEP model-paper PDFs (د. برق + أكاديمية ستيب المجانية; their reading recall file was left out) — regenerate rather than hand-edit. Progress `step.stats`, `step.wrongs`, `step.ok`; honor-board points 7 per question answered right (once each) + streak bonus. Listening: `elite/step/listening.js` (`window.STEP_LISTEN`) = 22 ORIGINAL recordings written by us (lectures/conversations on topics of the recalled STEP listening papers; the recalled Q&A file has no audio and unverifiable keys, so it was NOT imported), 49 Qs with 3 options, read aloud by the browser (speechSynthesis, 2 voices for conversations, speed select), transcript shown after answering; mock test = 20 listening + 40 reading + 40 grammar.
- `teacher.html` first panel «📊 نشاط الطلاب»: tabs اليوم / هذا الأسبوع + grade/section filter (sessionStorage `t-ac`); per active student the points earned per section (raw, before the cap) and, in week view, the last 7 days; idle students folded. Data = `parts.act` {day, week, t: {sec: pts today}, w: {sec: pts this week}, h: {day: pts} last 14 days}, computed by `activity()` in honor.js from the local ledger `act` (not backed up; starts at zero on first run). honor.js exports `dayNo`.
- `teacher.html` pending names, newest registrations, level-check results (+ open post test, CSV), Word Quest follow-up, honor list CSV.
- `level/` after test opens by itself 4 weeks after the pre test (was 6 until 3 Nov 2026) (teacher flag `postOpen` can open the first one early), then a new after test every 4 weeks (rules: `fourWeeksAfter`); the earlier post moves to `prev` (saveLevel does this); after tests alternate forms (post, pre, post…), drafts `lv2-draft-post<n>`. Ahmed must paste firestore.rules into the Firebase console for this.
- `level/` before/after placement test, version 2 (harder, since 1 Nov 2026): 32 Q (vocab 10, grammar 10, reading 6, listening 6), bands A1×2/A2×10/B1×10/B2×10, each pre item has a same-level twin in the post form; levels Pre-A1…B2. Results with `at` < `NEW_AT` are the old easy version: the student is asked to retake the pre test (rules allow replacing an old pre once; teacher.html marks «نسخة قديمة»). Drafts use `lv2-draft-`.
- `journey/word-quest.html` 50 units (4000 Essential English Words 1 lists + theme units): hero dashboard, journey map, daily spaced review (`wq-srs`), daily goal/streak, record-and-compare pronunciation (no automatic speech scoring — removed as unreliable).
- `kids/` home = «مسيرة البطل» journey map (`LANDS`/`ST` in kids/index.html): 27 stations in 6 lands (بستان الحروف → قمة الأبطال), each station offers 3 missions (learn / listen / read / story / write / spell / games); one finished mission opens the next station, 3 = ⭐⭐⭐; «🚀 أنا بطل متقدم» picks a land to start from (`JR.j`: first station of every land up to it opens); a chest (+5 stars) ends each land. Progress `kd-jr` {d:{'station.door':1},c:{land:1}}. Mission done = endScreen reached, 6 learn cards tapped, or 3 letters written; bottom bar `#jbar` + «ارجع إلى المحطة». The old sectioned home is now «كل الأقسام» (`allSections`, #all).
- `kids/` Kids Club (primary school): letters/numbers/colours/shapes, letter writing (tracing), 16 picture topics, phrases, classroom phrases, page-turning storybook (20 stories in 4 levels; L2–L4 have a "New Words" page; L4 = advanced, true/false questions). Home order: review box → story corner (story of the day + covers) → basics → picture words → phrases → games → advanced corner (Hero Stories, Build it! word order, Grammar, Opposites, Super Spell). Back button: every screen is a history entry (#sec / #story-n), so phone back stays inside Kids Club, read/spell/memory games, stickers; own manifest + lion-cub icon. Mistakes: wrong answer → try again (right answer glows after 2 tries), question re-asked 2 rounds later, and stored in `kd-fix` (Leitner: 10 min, 1 day, 3 days) → home "🔁 حان وقت المراجعة" box and due items mixed into the next game.

Words/sentences are embedded in the page (inappropriate items — alcohol, pork, dating etc. — were filtered out when it was generated).
